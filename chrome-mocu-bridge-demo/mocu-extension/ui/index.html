انتخاب Agent

Agent باید از قبل در صفحهٔ Agents مکو ساخته شده باشد. محتوای صفحه به عنوان دادهٔ غیرقابل‌اعتماد برایش فرستاده می‌شود.

فرمان به Chrome

کلیک واقعاً روی صفحه اثر می‌گذارد. ابتدا فقط روی سایت و عنصر آزمایشی کار کن. اجرای JavaScript دلخواه در این نمونه ممکن نیست.
