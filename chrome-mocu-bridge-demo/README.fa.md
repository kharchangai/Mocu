# نمونهٔ پل Chrome ↔ Mocu

نمونهٔ آموزشی برای ارتباط دوطرفه: افزونهٔ Chrome متن زبانهٔ فعال را می‌فرستد تا یک Agent ذخیره‌شده در Mocu آن را تحلیل کند؛ از App مکو هم می‌توان فرمان محدودِ خواندن، پرکردن فیلد یا کلیک را به Chrome فرستاد.

## راه‌اندازی

1. در Mocu ← **Extensions** ← **Install from Folder**، پوشهٔ `mocu-extension` را انتخاب کن.
2. در **Apps** مکو، **Chrome ↔ Mocu Bridge Demo** را باز کن و **شروع پل** را بزن.
3. رمز pairing را کپی کن.
4. در Chrome به `chrome://extensions` برو، **Developer mode** و سپس **Load unpacked** را انتخاب کن؛ پوشهٔ `chrome-extension` را بده.
5. پنجرهٔ افزونهٔ Chrome را باز کن، رمز را وارد کن و **اتصال** را بزن.
6. در App مکو Agent را انتخاب کن؛ حالا در Chrome با **ارسال صفحه به Agent** متن صفحه را بفرست.
7. برای کنترل از Mocu، از همان App یکی از دکمه‌های خواندن/پرکردن/کلیک را بزن.

## فایل‌ها

- `mocu-extension/manifest.json`, `index.js`: پل محلی WebSocket و فراخوانی Agent از SDK مکو.
- `mocu-extension/ui/index.html`: صفحهٔ App برای شروع/توقف پل، انتخاب Agent و کنترل مرورگر.
- `chrome-extension/manifest.json`, `service-worker.js`, `popup.html`: افزونهٔ Chrome Manifest V3.

سرور فقط روی `127.0.0.1:38741` گوش می‌دهد و pairing token تصادفی می‌سازد. SDK مکو داخل پوشهٔ افزونه vendored شده است؛ وابستگی WebSocket هنگام نصب با npm نصب می‌شود.

صفحهٔ App مکو خودش فرمان‌های مرورگر را ارسال می‌کند. همچنین فرمان `controlChrome` در افزونه تعریف شده؛ اگر این افزونه را برای همان گفت‌وگو/Agent فعال کنی، Agent هم می‌تواند از آن استفاده کند. 

صفحه فقط با کلیک صریح کاربر ارسال می‌شود. فقط اکشن‌های مشخص‌شده پیاده‌سازی شده‌اند و کد JavaScript دلخواه اجرا نمی‌شود. بااین‌حال کلیک/پرکردن ممکن است صفحه را تغییر دهد؛ اول روی صفحهٔ آزمایشی امتحان کن و کلیک‌های حساس را انجام نده. محتوای صفحه قابل‌اعتماد نیست و نباید دستورات داخل آن را به‌عنوان درخواست کاربر تلقی کرد. Pairing token را به کسی نده.

این یک دموی محلی است، نه نسخهٔ آمادهٔ انتشار. سرور تا وقتی Mocu باز است زنده می‌ماند؛ پس از بستن Mocu، دوباره از App پل را شروع و Chrome را وصل کن. بعضی صفحه‌ها مثل `chrome://` یا Chrome Web Store اجازهٔ دسترسی از طریق افزونه را نمی‌دهند.

## جریان ساده

```text
Chrome ── متن صفحه ──> WebSocket محلی ──> Mocu extension ──> Agent
Chrome <── نتیجهٔ Agent ────────────────────────────────────────
Mocu App ── read/click/fill ──> Mocu extension ──> Chrome
```

وابستگی‌ها: Mocu، Google Chrome، Node.js 20+ و دست‌کم یک Agent ذخیره‌شده. نصب دستی و استفاده فقط برای کاربر محلی.
