# Mocu Docs Map

## Choose the focused guide

Use the guide that matches the question. Read the linked guide explicitly when you need its details; links are navigation, not automatic document loading.

- **What is Mocu / how do I use it / what do the pages do / normal chat vs project chat:** [Mocu User Guide](mocu-user-guide.md)
- **Slash commands, `/` menu, Focus mode, Step-by-Step mode:** [Mocu Chat, Slash Commands, Focus and Step-by-Step](mocu-chat-commands.md)
- **Projects, project chat, project memory, specialist memory tags:** [Mocu Projects](mocu-projects.md)
- **Reminders, scheduling, scheduled agent runs, recurrence:** [Mocu Schedule](mocu-schedule.md)
- **Skills, SKILL.md, creating/installing skills, `/skill`:** [Mocu Skills](mocu-skills.md)
- **Knowledge docs, doc search, doc tools:** [Mocu Knowledge Docs](mocu-knowledge-docs.md)
- **Notes, remembering things, note tools:** [Mocu Notes](mocu-notes.md)
- **Extensions, install from ZIP/folder, `/extension`:** [Mocu Extensions](mocu-extensions.md)
- **MCP servers, transports, `mcpServers` JSON, `/mcp`:** [Mocu MCP Servers](mocu-mcp.md)
- **Agents, create/update agents, `/agent`, scheduled agents:** [Mocu Agents](mocu-agents.md)
- **Settings, API keys, models, speech, retrieval options:** [Mocu Settings](mocu-settings.md)
