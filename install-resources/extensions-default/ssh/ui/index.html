SSH

Mocu extension app

SSH Workbench

Set up the SSH extension safely, prepare clear requests for remote commands and file transfers, and keep credentials on your computer.

This page prepares requests; it does not connect to a server. To run a request, open a Mocu chat, select the SSH extension (for example with /extension), then paste the prepared text. Review remote commands before running them.

Configure the connection

In Mocu's SSH extension settings, enter environment-variable names and local file paths only. Put the actual host, username, and password or passphrase values in a private .env file on this computer.

SSH_HOST_ENVVariable name containing the server hostname or IP, e.g. SSH_HOST.
SSH_USERNAME_ENVVariable name containing the SSH username, e.g. SSH_USERNAME.
SSH_PORTServer port as a number; defaults to 22.
SSH_PASSWORD_ENVPassword variable name, e.g. SSH_PASSWORD; used when no private key is configured.
SSH_PRIVATE_KEY_PATHOptional path to a private key file on this computer. A key is used instead of a password.
SSH_KEY_PASSPHRASE_ENVOptional variable name for the key passphrase.
ENV_FILE_PATHPath to your private .env file. If empty, the extension checks its own folder.

Example .env shape

Replace placeholders locally. Never paste real values into Mocu settings, this page, chat, or source control.

SSH_HOST=<your-server-host>
SSH_USERNAME=<your-username>
SSH_PASSWORD=<your-password>
SSH_KEY_PASSPHRASE=<optional-key-passphrase>

For key-based login, set the private-key path and leave the password variable unset. Only add variables you actually use, and protect the .env and private-key files with appropriate file permissions.

Prepare a remote command

Enter the command you want run on the configured server. The generated text is only a chat request; this page never executes it.

Avoid including passwords, private keys, or other secrets.

Prepare a file upload

Provide an absolute local file path and the destination path on the server. Existing remote files are not overwritten by default.

Prepare a file download

Provide the path of the remote file and an absolute destination path on this computer. Existing local files are not overwritten by default.

SSH connection details are read from the extension's saved settings and your local .env file. The forms above are not saved by this page.
