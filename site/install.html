Setup guide · about 10 minutes

Install Mocu on Windows

Download, connect a model provider, create a project, and build your first agent. If something breaks at any step, there is a troubleshooting list at the bottom.

1. Download the installer

Open the GitHub releases page and grab the newest release. Windows builds are attached as .exe (setup) and .msi (installer package) — either works. Pick the architecture that matches your machine: x64 for most Intel and AMD PCs, arm64 if you are on an ARM device.

Mocu is in alpha. Release names include the version, so note which one you installed when you report a problem.

2. Run it

Run the file and follow the prompts. Two things are normal for alpha builds:

  • SmartScreen warning. Unsigned builds trigger "Windows protected your PC". Choose More info → Run anyway.
  • No auto-update promise. Check the releases page occasionally; there is no silent updater guarantee in alpha.
Mocu writes its data to your user profile, and per-project data to a .mocu/ folder inside each project. Keep that folder if you want a project's memory and history to survive — and see the privacy policy for what is stored.

3. Connect a model provider

Mocu does not ship with a model. Open Settings, add the provider you already pay for, and paste its API key. Costs are billed by that provider, not by Mocu.

Worth knowing before you configure it:

  • Use one strong model for planning and a cheap one for grunt work. Most agent cost sits in the cheap, high-volume steps.
  • Start small. A short task with a smaller model tells you whether your key, endpoint and model name are right before a long run burns tokens.
  • Keys stay local in your app data directory. Do not paste keys into screenshots, issues or chat logs.

4. Create a project

A project is the unit that makes Mocu different from a chat window. Point it at the folder you actually work in. Inside that project you get scoped chats, notes, docs, memory and history.

  • Ask for a task and the agent sees the project's files, not your whole disk.
  • Tell it something durable about this project and it stays with the project, not with the conversation.
  • Switch to another project and the context does not leak across.

5. Create your first agent

Ask in plain language. For example: 

Create an agent that reads my saved documents and drafts a weekly summary
in my own style. It should use the documents folder as its source of truth
and never invent numbers that are not in the documents.

Mocu creates the agent definition with a role, instructions and the tools it may call. Then:

  • Select it with /agent in a chat, or just ask for it by name.
  • Let it delegate to another agent if the task needs research plus writing.
  • Ask Mocu to update the agent when your workflow changes — no hand-editing required.
  • Schedule it to run on a recurring job once you trust the output.

Optional: the parts that need extra setup

Python extensions

Some bundled extensions run on Python. If one fails to start, install Python and make sure it is on your PATH.

Browser Use

Browser automation goes through the Browser Bridge, which connects to a real browser session so the agent uses your own logged-in state instead of a sandbox. Enable it, then select it with /extension for the request that needs it.

Computer Control

The desktop automation extension can open apps, read windows, click and type. Treat it like handing someone your mouse: enable it per request, watch the first few runs, and keep destructive actions manual.

Building from source instead

If you want to run the development build, you need Node.js 22, Rust, and the Tauri prerequisites for Windows. Full commands for Windows, macOS and Linux are in the README. 

git clone https://github.com/kharchangai/Mocu.git
cd Mocu
npm install
npm run tauri dev

Troubleshooting

  • The app opens but nothing answers. No provider configured, or an invalid key. Re-check Settings and try a one-line prompt with the smallest model you have.
  • An extension does not appear. Installing an extension is not the same as activating it. Select it with /extension for that request.
  • A Python extension crashes. Python is missing or not on PATH.
  • Scheduled runs did not fire. Mocu has to be open at the scheduled time. On startup it catches up recently missed items.
  • Browser automation stops on a page. Expected in alpha on dynamic sites. Take over, finish the step yourself, and report the site.
  • Costs climbed fast. Long agent chains with a large model are the usual cause. Route routine steps to a smaller model and keep runs short while you tune the workflow.

Still stuck? Open an issue with your version, your provider and model, and what you expected — github.com/kharchangai/Mocu/issues. Never include API keys or private screenshots.
