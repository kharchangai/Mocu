> **مکو برای جایگزین شدن با شما ساخته نشده؛ برای بیشتر کردن توان شما ساخته شده است.**

مکو یک فضای کاری دسکتاپ برای هوش مصنوعی است که در آن تیمی از ایجنت‌های شخصی را دقیقاً حول شیوهٔ کاری **خودتان** می‌سازید. روش‌هایتان را به آن‌ها یاد می‌دهید، ابزارها و دانش به‌روز را در اختیارشان می‌گذارید و بعد همه‌چیز را در یک جا پیش می‌برید—از یک کار فوری تا پروژه‌ای که ماه‌ها ادامه دارد.

- **بدون نیاز به برنامه‌نویسی.** نیازتان را به زبان ساده بگویید؛ مکو در ساختن ایجنت، اسکیل یا ابزار کمک می‌کند.
- **تصمیم نهایی با شماست.** ایده‌ها، قضاوت و هدف‌ها از آنِ خودتان می‌مانند. ایجنت‌ها کار را جلو می‌برند، نه تصمیم را.
- **بین نشست‌ها هیچ‌چیز از صفر شروع نمی‌شود.** پروژه‌ها، حافظه، نوت‌ها و زمان‌بندی، زمینهٔ کار شما را زنده نگه می‌دارند.

## تفاوت، در یک پاراگراف

یک دستیار عمومی هر گفت‌وگو را در حالی شروع می‌کند که هیچ‌چیز از کار شما نمی‌داند. قواعد ویرایشی شما، آخرین تغییرات محصولتان یا روش بازبینی تیم‌تان را نمی‌شناسد؛ پس هر بار باید همه را از نو توضیح دهید. مکو از سمت مقابل ساخته شده است: **روش‌های شما در اسکیل‌ها، واقعیت‌های شما در اسناد، متخصص‌های شما در ایجنت‌ها و تاریخچهٔ کارتان در حافظهٔ پروژه زندگی می‌کند.** هرچه بیشتر از آن استفاده کنید، کمتر تکرار می‌کنید.

## تیم بسازید—نه یک پرامپت طولانی‌تر

در مکو فقط با توضیح نیازتان به زبان طبیعی، **ایجنت‌های متخصص و شخصی‌سازی‌شده** برای کارتان می‌سازید.

> «یک ایجنت پژوهش بساز که از اسناد مرجع من استفاده کند، یک ایجنت نویسندگی که از سبک من پیروی کند و یک بازبین که نتیجه را بررسی کند. از نویسنده بخواه پژوهش و بازبینی را به آن دو واگذار کند.»

هر ایجنت می‌تواند دستورالعمل‌ها، ابزارها، اسکیل‌ها، اکستنشن‌ها، مدل و ایجنت‌های فرعی خودش را داشته باشد. با یک متخصص مفید شروع کنید و هرجا نیازهایتان رشد کرد، ایجنت‌ها را به سیستم‌های پیشرفته‌تری وصل کنید—بدون اینکه لازم باشد تعریفشان را دستی بنویسید.

- **شخصی‌سازی کنید:** نقش، سبک کار و ابزارهای مجاز هر ایجنت را مشخص کنید.
- **سیستم‌های قابل استفادهٔ مجدد بسازید:** متخصص‌ها را کنار هم بگذارید و واگذاری کار به ایجنت‌های دیگر را ممکن کنید.
- **هر وقت لازم شد صدا بزنید:** یک ایجنت ذخیره‌شده را با دستور `/agent` انتخاب کنید یا به زبان ساده از مکو بخواهید کاری را واگذار کند.
- **به‌مرور بهترشان کنید:** با تغییر روند کارتان، از مکو بخواهید ایجنت را به‌روزرسانی کند.

این‌ها دستیارهای قابل استفادهٔ مجدد شما هستند که برای مسئولیت‌های خودتان ساخته شده‌اند، نه یک شخصیت هوش مصنوعی یکسان برای همه. ایجنت‌ها هنگام فراخوانی اجرا می‌شوند و اجراهای زمان‌بندی‌شده امکان خودکارسازی کارهای مشخص را در زمان دلخواه شما می‌دهد.

## مکو را متناسب با نیازهایتان گسترش دهید

روند کارتان نباید به قابلیت‌های ازپیش‌ساختهٔ یک برنامه محدود شود. **اکستنشن‌ها ابزارها و یکپارچه‌سازی‌های تازه‌ای اضافه می‌کنند** تا مکو همراه با نیازهای کاری شما رشد کند.

اکستنشن‌های همراه برنامه را از صفحهٔ Extensions نصب کنید یا یک اکستنشن را از پوشه یا فایل ZIP اضافه کنید. برای استفاده در یک درخواست، اکستنشن‌ها را با دستور `/extension` انتخاب کنید. (نصب به‌تنهایی اکستنشن را در گفت‌وگو فعال نمی‌کند.)

**لازم نیست خودتان کدنویسی کنید.** قابلیت موردنظرتان را توضیح دهید و از مکو بخواهید اکستنشن سفارشی بسازد—همراه با کد و بسته‌بندی. در پشت صحنه اکستنشن‌ها به شکل برنامه‌های Node.js یا Python اجرا می‌شوند؛ پس توسعه‌دهندگان می‌توانند با SDKهای همراه برنامه آن‌ها را مستقیم بسازند و پشتیبانی MCP راه دیگری برای اتصال ابزارهای خارجی است.

### ایجنت‌ها + اسکیل‌ها + اکستنشن‌ها = روند کاری هوشمند خودتان

| جزء | چه چیزی اضافه می‌کند؟ |
|---|---|
| **ایجنت‌ها** | چه کسی کار را انجام می‌دهد: متخصص‌هایی با نقش، ابزار و قابلیت واگذاری کار. |
| **اسکیل‌ها** | کار باید چگونه انجام شود: دستورالعمل‌ها و روش‌های قابل استفادهٔ مجدد. |
| **اکستنشن‌ها** | سیستم چه کارهایی می‌تواند انجام دهد: ابزارها و یکپارچه‌سازی‌های تازه. |

این اجزا در کنار هم به شما امکان می‌دهند بدون برنامه‌نویس بودن، روندهای کاری پیچیده بسازید. پیچیدگی در سیستمی که می‌سازید زندگی می‌کند، نه در دستورهایی که هر روز تکرار می‌کنید.

برای نمونه، یک روند تولید محتوا می‌تواند ایجنت پژوهش، نویسنده و بازبین را با یک اسکیل برای فرایند ویرایش شما و اکستنشن ابزارهای انتشار ترکیب کند. اسناد شما اطلاعات به‌روز محصول را تأمین می‌کنند و نوت‌ها اولویت‌های شخصی‌تان را در دید نگه می‌دارند.

## تازه در نسخهٔ ۰٫۲٫۰: برای کارهای تکراری اپ بسازید

**اپ‌های مکو** به شما امکان می‌دهند اپ‌های سفارشی با رابط کاربری اختصاصی بسازید و همان‌جا داخل مکو بازشان کنید. برای کاری که مرتب تکرار می‌شود رابط دلخواهتان را توصیف کنید—و به‌جای یک گفت‌وگوی دیگر، یک پنل مخصوص همان کار بگیرید.

اپ‌ها از طریق اکستنشن‌ها به مکو وصل می‌شوند و با مجوزهایی که تأیید می‌کنید می‌توانند از قابلیت‌های پشتیبانی‌شدهٔ مکو استفاده کنند؛ برای نمونه ایجنت‌های ذخیره‌شده را اجرا کنند یا با فایل‌های انتخاب‌شده کار کنند. دسترسی اپ‌ها به قابلیت‌ها و فایل‌های مکو همیشه با مجوزهای اکستنشن کنترل می‌شود.

## دانش به‌روز در اختیار ایجنت‌هایتان بگذارید—نه فقط دانش زمان آموزش مدل

مدل‌ها به‌طور خودکار از آخرین تغییرات محصول، فرایندهای داخلی یا قراردادهای پروژهٔ شما باخبر نمی‌شوند. **اسناد دانش مکو (Mocu Docs)** این اطلاعات را در اختیارشان می‌گذارد و به‌روز نگه می‌دارد.

مطالب مرجع، دستورالعمل‌ها، اطلاعات محصول یا راهنماها را به‌صورت اسناد دانشِ قابل جست‌وجو ذخیره کنید. مکو برای درخواست فعلی، ارجاع‌های مرتبط را پیدا می‌کند و هرگاه به جزئیات نیاز باشد متن کامل سند را می‌خواند.

- **دانش را به‌روز نگه دارید:** یک سند را به‌روزرسانی کنید و همهٔ گفت‌وگوهای بعدی از آن سود می‌برند.
- **به ایجنت‌ها زمینه بدهید:** قواعد، واقعیت‌ها و روش‌هایی را بدهید که برای درست انجام دادن کار لازم است.
- **چسباندن مکرر زمینه را کنار بگذارید:** دانش مفید در همهٔ گفت‌وگوها در دسترس می‌شود.
- **بدون راه‌اندازی سامانهٔ RAG شروع کنید:** به‌جای سرهم‌کردن یک سامانهٔ بازیابی خارجی، از روند دانشِ داخلی مکو استفاده کنید.

مکو از اسنادی که خودتان می‌نویسید بازیابی می‌کند؛ مدل را دوباره آموزش نمی‌دهد و دانشی که اضافه نکرده‌اید از خودش نمی‌سازد.

## نوت‌هایی که خواسته‌هایتان را به گفت‌وگو برمی‌گردانند

همه‌چیز به یک سند کامل نیاز ندارد. **نوت‌ها** برای چیزهای مهمی هستند که می‌خواهید دم دستتان بمانند: ترجیحات، تصمیم‌ها، برنامه‌ها و چیزهایی که نمی‌خواهید فراموش کنید.

> «یادت باشد: پیش از انتشار اطلاعیهٔ نسخهٔ جدید، تصویرهای صفحه را به‌روزرسانی کنم و پیوند دانلود را بررسی کنم.»

نوت‌ها **دقیقاً همان‌طور که می‌نویسید** ذخیره می‌شوند. وقتی گفت‌وگویی به موضوعی مرتبط برسد، مکو می‌تواند نوت‌های مربوط را پیدا و استفاده کند—یا هنگام کمک به انجام کار، آن‌ها را به شما یادآوری کند.

برای دانش مرجع ساختارمند از **Docs**، برای زمینه و خواسته‌های شخصی از **Notes** و وقتی یادآوری در زمان مشخصی می‌خواهید از **Schedule** استفاده کنید.

## روزتان را برنامه‌ریزی کنید—و ایجنت‌ها را زمان‌بندی کنید

سامانهٔ زمان‌بندی مکو هم یادآوری‌های روزمره و هم **اجرای خودکار ایجنت‌های ذخیره‌شده** را پوشش می‌دهد.

- برای جلسه، مهلت یا کار، یادآوری تنظیم کنید.
- برای یک ایجنت متخصص، با دستورالعمل و در تاریخ و ساعت دلخواه اجرا زمان‌بندی کنید.
- یادآوری‌ها یا اجرای ایجنت‌ها را روزانه، هفتگی یا ماهانه تکرار کنید.
- زمان‌بندی‌ها را از صفحهٔ Schedule مدیریت و اجراهای گذشته را بررسی کنید.

گزارش صبحگاهی با سبک خودتان می‌خواهید؟ ایجنتش را یک بار بسازید و بعد با ورودی و ساعت دلخواه زمان‌بندی‌اش کنید. می‌خواهید تعهدی را فراموش نکنید؟ به‌جایش یک یادآوری تنظیم کنید.

**برای اجرا شدن زمان‌بندی‌ها در ساعت مقرر، مکو باید باز باشد.** هنگام راه‌اندازی، موارد به‌تازگی ازدست‌رفته جبران می‌شوند و زمان‌بندی‌های تکرارشونده به نوبت آینده منتقل می‌شوند—همهٔ اجراهای ازدست‌رفته یکی‌یکی اجرا نمی‌شوند.

## برای کارهایی ساخته شده که از یک گفت‌وگو طولانی‌ترند

پروژه‌های بلندمدت نباید هر بار با شروع از صفر همراه باشند. **پروژه‌های مکو** یک فضای کاری را به پوشه‌ای در رایانه‌تان وصل می‌کنند و تاریخچهٔ گفت‌وگو و حافظهٔ پروژهٔ مخصوص خودش را به آن می‌دهند.

مکو گفت‌وگوهای پروژه را ذخیره می‌کند و هنگام ادامهٔ کار، بخش‌های مرتبط کارهای قبلی را بازیابی می‌کند. حافظهٔ شخصیِ سراسری زمینه‌ای دربارهٔ شما را در نشست‌های مختلف نگه می‌دارد و حافظهٔ مختص پروژه، کارهای ادامه‌دار را به فضای کاری درست گره می‌زند.

بخش‌های کامل‌شدهٔ Focus و گام‌های تمام‌شدهٔ Step-by-Step، **خلاصه‌های فشردهٔ حافظه** بر جای می‌گذارند. کارهای بعدی بر همان خلاصه‌ها بنا می‌شوند و فقط در صورت نیاز به جزئیات می‌روند—به‌جای آنکه متن کامل گفت‌وگو در هر فراخوانی مدل گنجانده شود.

نتیجه، پیوستگی در پروژه‌های بلندمدت و چندنشستی است: توضیح‌های تکراری کمتر و زمینهٔ قابل‌مدیریت‌تر. حافظه به حفظ روند کار کمک می‌کند، اما یادآوری بی‌نقص را تضمین نمی‌کند و محدودیت زمینهٔ مدل را از میان نمی‌برد.

## در Focus متمرکز شوید یا گام‌به‌گام پیش بروید—در همان گفت‌وگوی پروژه

کارهای بزرگ همیشه به یک شیوهٔ کار نیاز ندارند. مکو دو راه برای پیش‌بردنشان می‌دهد، بدون اینکه بین گفت‌وگوهای جداگانه جابه‌جا شوید.

### Focus: روی یک هدف بمانید

در گفت‌وگوی پروژه با `/focus <goal>` شروع کنید. کار را در بخش‌های انعطاف‌پذیری پیش ببرید که کنترلشان دست خودتان است و هرجا کار ایجاب کرد بخش تازه اضافه کنید. برای رفتن به بخش بعدی بگویید **«بخش بعدی»** و برای پایان دادن بگویید **«پایان Focus»**.

وقتی هدف را می‌دانید اما می‌خواهید در مسیر فرصت بررسی و انتخاب بخش بعدی را داشته باشید، Focus را انتخاب کنید.

### Step-by-Step: کار را به برنامه‌ای قابل‌مدیریت تبدیل کنید

در گفت‌وگوی پروژه با `/step <task>` شروع کنید. مکو برنامه‌ای از گام‌های کوچک پیشنهاد می‌دهد. آن را بررسی کنید و بعد هر بار یک گام را با پیشرفت قابل‌مشاهده و خلاصه‌های ذخیره‌شده پیش ببرید.

وقتی پیش از شروع برنامه‌ای روشن و مسیری ساختارمند می‌خواهید، Step-by-Step را انتخاب کنید.

**هر دو حالت فقط در گفت‌وگوهای پروژه کار می‌کنند.** هر بخش یا گام تکمیل‌شده در حافظهٔ پروژه ذخیره می‌شود تا بخش بعدی بر کارهای قبلی بنا شود.

## مناسب چه کسانی است

- **توسعه‌دهندگان و بنیان‌گذاران فنی** — ایجنت‌هایی با ابزارهای واقعی، اتصال‌های MCP و اکستنشن‌های Node.js یا Python؛ ساختاری که می‌توانید بررسی و گسترش دهید.
- **تولیدکنندگان محتوا و بازاریاب‌ها** — زنجیرهٔ پژوهش ← نوشتن ← بازبینی که از راهنمای سبک شما پیروی می‌کند، به ابزارهای انتشارتان وصل است و زمینهٔ کمپین در تمام پروژه زنده می‌ماند.
- **کارجویان مستقل و تیم‌های کوچک** — گزارش صبحگاهی، گزارش‌های زمان‌بندی‌شده و یادآوری‌هایی که به یادِ کسی وابسته نیستند.

اگر دستیاری می‌خواهید که خودتان شکلش بدهید—نه فقط با آن گپ بزنید—مکو برای شما ساخته شده است.

نصب‌کننده‌های آماده امروز **برای ویندوز** موجودند؛ **نصب‌کنندهٔ macOS به‌زودی** عرضه می‌شود. تا آن زمان می‌توانید مکو را با دستورالعمل‌های پایین روی macOS یا Linux از روی کد منبع بسازید.

### فضای کاری‌تان را راه‌اندازی کنید

1. در **Settings** یک ارائه‌دهندهٔ سازگار با OpenAI وصل کنید: کلید API، نشانی پایه و نام مدل‌ها. مکو به مدل خاصی وابسته نیست—انتخاب ارائه‌دهنده و مدل‌ها با شماست.
2. نخستین ایجنت شخصی‌تان را توصیف کنید و از مکو بخواهید بسازدش.
3. یک سند دانش و یک نوت دربارهٔ شیوهٔ کاری دلخواهتان اضافه کنید.
4. اکستنشن‌های موردنیازتان را نصب و انتخاب کنید.
5. برای کارهای ادامه‌دار یک **Project** باز کنید و بعد `/focus` یا `/step` را امتحان کنید.

برای اکستنشن‌های Node به Node.js و برای اکستنشن‌های Python به Python نیاز دارید. قابلیت‌های هوش مصنوعی به کلید API نیاز دارند و استفاده از ارائه‌دهنده ممکن است هزینه داشته باشد؛ جست‌وجوی وب هم به کلید API سرویس Perplexity نیاز دارد.

## نکات نسخهٔ آلفا

مکو یک آلفای ابتدایی است و این را صادقانه می‌گوید. پیش از اتکا به آن:

- **منتظر تغییر باشید.** بین نسخه‌ها ممکن است اشکال، قابلیت‌های ناتمام یا تغییرات ناسازگار پیش بیاید.
- **خروجی‌ها را بررسی کنید.** محتوا، کد و اقدام‌های ابزارها را پیش از استفاده بازبینی کنید. اکستنشن‌ها و اپ‌های تولیدشده آزمایش خودشان را لازم دارند.
- **قبل از اجرای روندهایی که فایل‌ها را تغییر می‌دهند، از فایل‌های مهم نسخهٔ پشتیبان بگیرید** و فقط از اکستنشن‌های مورداعتماد استفاده کنید.
- **نیازمندی‌ها را در نظر بگیرید.** هزینهٔ ارائه‌دهنده، کلیدهای API و زمان‌اجرای لازم (Node.js، Python) برای هر قابلیت جداست؛ نصب به‌تنهایی هرگز به اکستنشن دسترسی در گفت‌وگو نمی‌دهد.
- **زمان‌بندی‌ها به باز بودن برنامه نیاز دارند** و ممکن است مشکلات ساخت یا اجرای مختص سیستم‌عامل روی macOS و Linux پیش بیاید.

## ساخت از روی کد منبع

بخش دسکتاپ مکو از **Tauri 2 + Rust** و رابط کاربری آن از **React + TypeScript + Vite** استفاده می‌کند.

به **Git**، نسخهٔ پایدار **Rust**، **Node.js 22.12+** (یا نسخهٔ جدیدتر و سازگار LTS) و وابستگی‌های بومی لازم برای سیستم‌عاملتان نیاز دارید. اگر قصد استفاده از اکستنشن‌های Python را دارید، **Python 3** را هم نصب کنید؛ برای کامپایل خود مکو نیازی به آن نیست.

برای پیش‌نیازها و عیب‌یابی مختص هر سیستم‌عامل، [راهنمای پیش‌نیازهای Tauri](https://v2.tauri.app/start/prerequisites/) را ببینید. دستورهای پایین ابزارهای توسعه را روی رایانه‌تان نصب می‌کنند؛ پیش از اجرا آن‌ها را بررسی کنید.

### Windows · PowerShell

ابزارهای لازم را نصب کنید:

```powershell
winget install --id Git.Git -e
winget install --id Rustlang.Rustup -e
winget install --id OpenJS.NodeJS.LTS -e

# اختیاری: برای اکستنشن‌های Python لازم است
winget install --id Python.Python.3.12 -e
```

[Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) را همراه با بارکاری **Desktop development with C++** و Windows SDK نصب کنید. Tauri به **Microsoft Edge WebView2** هم نیاز دارد که معمولاً در نسخه‌های جدید ویندوز از قبل نصب است.

پس از نصب، یک ترمینال تازه باز کنید تا ابزارها در `PATH` در دسترس باشند.

### macOS · Terminal

ابزارهای خط فرمان Xcode را نصب کنید و منتظر بمانید نصب کامل شود:

```bash
xcode-select --install
```

اگر [Homebrew](https://brew.sh/) را نصب کرده‌اید:

```bash
brew install git node@22
brew link --overwrite node@22

# اختیاری: برای اکستنشن‌های Python لازم است
brew install python

# Rust را نصب کنید و دستورهای نصب‌کننده را دنبال کنید
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

اگر نسخهٔ دیگری از Node نصب است، به‌جای پیوند‌دادن دوباره از مدیر نسخهٔ خودتان یا دستورالعمل‌های PATH در Homebrew استفاده کنید. ابزارهای دسکتاپ و صفحه‌نمایش ممکن است به مجوزهای حریم خصوصی macOS نیاز داشته باشند.

### Linux · Ubuntu / Debian

وابستگی‌های بومی را نصب کنید (نام بسته‌ها ممکن است در توزیع‌های مختلف فرق کند):

```bash
sudo apt update
sudo apt install -y git curl wget file build-essential pkg-config \
  libwebkit2gtk-4.1-dev libssl-dev libayatana-appindicator3-dev \
  librsvg2-dev libxdo-dev libx11-dev libxi-dev libxtst-dev

# اختیاری: برای اکستنشن‌های Python لازم است
sudo apt install -y python3 python3-pip python3-venv

# Rust را نصب کنید و دستورهای نصب‌کننده را دنبال کنید
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"

# نصب Node.js 22 با nvm؛ پیش از اجرا، نصب‌کننده را بررسی کنید
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
nvm install 22
nvm use 22
```

از توزیعی استفاده کنید که WebKitGTK 4.1 را ارائه می‌دهد. در توزیع‌های دیگر، بسته‌های معادل لازم است؛ راهنمای پیش‌نیازهای Tauri را ببینید. ابزارهای تصویربرداری از صفحه و ورودی ممکن است با توجه به محیط دسکتاپ، به‌ویژه در Wayland، محدودیت داشته باشند.

### دریافت مخزن، اجرا و ساخت

پس از نصب پیش‌نیازها، این دستورها را در **Windows، macOS یا Linux** اجرا کنید:

```bash
git clone https://github.com/kharchangai/Mocu.git
cd Mocu
npm install

# اجرای نسخهٔ کامل دسکتاپ در حالت توسعه
npm run tauri dev
```

برای ساخت بستهٔ قابل نصب روی همان سیستم‌عاملی که با آن کار می‌کنید، برنامهٔ توسعه را ببندید و اجرا کنید:

```bash
npm run tauri build
```

خروجی ساخت معمولاً در `src-tauri/target/release/bundle/` قرار می‌گیرد. برنامه را روی سیستم‌عامل مقصد بسازید؛ این دستور نصب‌کنندهٔ چندسکویی تولید نمی‌کند. امضای برنامه یا آماده‌سازی برای توزیع ممکن است به تنظیمات مختص هر سیستم‌عامل نیاز داشته باشد.

وابستگی‌های اکستنشن‌های Python باید جداگانه و طبق دستورالعمل هر اکستنشن نصب شوند؛ مکو به‌طور خودکار `pip install` را اجرا نمی‌کند.
